Matrix filters with ImageData

A convolution filter replaces each pixel's RGB values with weighted sums of neighboring values. The 3 × 3 matrix of weights is called a kernel. Multiply each neighboring value by its weight, add the nine products, then divide by the divisor. Repeat for red, green, and blue. 


        

        

            Every selection starts with the original pixels, so effects do not accumulate.
            At image borders, the nearest valid pixel is repeated.
